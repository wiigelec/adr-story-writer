# ADR Story Writer Product Design

This directory contains the human-readable Product Design for ADR Story Writer.
These Markdown documents own product meaning. Runtime Ruleset, Dataset,
application, schema, validation, and implementation artifacts must preserve this
Design but do not independently redefine it.

## Design corpus

- DP-100 — Story Writer Product Architecture
- DP-110 — Story State, Authority, and Acceptance
- DP-120 — Workflow, Dependency, and Reconciliation
- DP-130 — Artifact Identity and Cross-Layer Traceability
- DP-140 — Canon State, Events, and Narrative Time
- DP-150 — Prose, Style, Voice, and Manuscript
- DP-160 — Dataset, Working State, Save, and Persistence
- DP-170 — Schema Evolution, Ruleset Compatibility, Migration, and Rebinding
- DP-180 — Validation, Semantic Review, and Integrity
- DP-190 — Story Metadata, Extensibility, and Simplicity Boundaries

## Interpretation

DP-100 defines the product-wide model. The remaining documents refine
consequential product decisions needed for reliable long-form authoring across
many sessions, revisions, and persisted story artifacts.

This Design intentionally establishes meaning before Planning selects concrete
Functional Sets, physical schemas, algorithms, commands, validations, or
implementation mechanisms.
